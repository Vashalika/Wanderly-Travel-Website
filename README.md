## ✨ About the Project

**Wanderly** is a modern, visually attractive, and responsive Travel & Tourism website created using **HTML5 and CSS3**.

The website is designed to provide users with an engaging experience where they can explore beautiful destinations, discover attractive travel packages, view travel galleries, and read traveller testimonials.

The project focuses on creating a clean, professional, and user-friendly interface with modern UI elements, smooth hover effects, attractive cards, responsive layouts, and easy navigation.

---

## 🎯 Purpose of the Project

The main purpose of this project is to design and develop a professional-looking Travel & Tourism website using front-end web development technologies.

This website allows users to:

- 🌍 Explore beautiful travel destinations
- ✈️ Discover exciting travel packages
- 🏔️ Learn about popular tourist locations
- 🔍 Search for dream destinations
- 💬 Read traveller testimonials
- 📸 Explore beautiful travel images
- 📱 Access the website on different screen sizes

This project was also created to practice and demonstrate skills in **HTML, CSS, responsive design, layouts, cards, hover effects, and modern website UI development**.

## 🚀 How to Run the Project

### Method 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.

### Method 2 — Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open the `index.html` file.
3. Run the project using the **Live Server** extension.
4. The website will open in your browser.
